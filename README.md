# AI 쇼츠 자동 생성기

상품 URL · 상품 정보 · 사진 · 영상을 넣으면 Claude Code 가 보고 대본/장면을 짜고,
Windows TTS 와 ffmpeg 로 9:16 쇼츠(MP4)를 만든다. 말로 수정하기, 장면 직접 수정, 버전 기록 지원.

## 설치

파이썬 패키지는 필요 없다(표준 라이브러리만 사용). 아래 프로그램만 있으면 된다.

### 필수
| 항목 | 이유 | 설치 |
|---|---|---|
| Windows 10/11 | 음성은 Windows 내장 TTS, 글꼴은 `C:\Windows\Fonts` 사용. Mac/Linux 미지원 | - |
| 한국어 음성 (Microsoft Heami) | AI 음성 6종이 모두 이 음성 기반 | 한국어 Windows 는 보통 기본 포함. 없으면 설정 > 시간 및 언어 > 언어 및 지역 > 한국어 > 언어 옵션 > 음성 |
| Python 3 | 실행 | python.org (설치 시 "Add to PATH" 체크) |
| ffmpeg / ffprobe | 영상 렌더링 | `winget install Gyan.FFmpeg` |
| Claude Code + 로그인 | AI 기획·수정·캡션 (Claude 유료 구독 Pro 이상) | `irm https://claude.ai/install.ps1 \| iex` 후 `claude` 실행 → `/login` |

### 선택
- **GPT**: Codex CLI + ChatGPT 계정 로그인. Node.js 필요. `npm i -g @openai/codex` 후 `codex login`.
  AI 설정 > 모델에서 GPT-5.6 Terra/Luna 선택. 무료 계정은 사용 한도에 금방 걸린다.
- **인스타그램 스킬**: 아래 "인스타그램 스킬" 참고. 저장소에 포함되어 있지 않다.
- **글꼴**: 맑은 고딕은 기본. HY·휴먼 계열은 한컴오피스 등이 설치된 PC 에만 있고, 없으면 목록에서 빠진다.

> 테스트 환경: Windows 11, Python 3.14, ffmpeg 8.1. 다른 버전/깨끗한 PC 에서의 설치는 아직 검증하지 않았다.

## 실행
```
python app.py
```
브라우저에서 http://127.0.0.1:8766 이 열린다. 기본 BGM·효과음은 첫 실행 때 자동 생성된다.
PowerShell 창을 닫거나 Ctrl+C 를 누르면 꺼진다. 이미 켜져 있는데 또 실행하면 "포트를 이미 쓰고 있습니다" 안내가 나온다.

오른쪽 위 배지로 연결 상태를 확인한다: `Claude Code 연결됨`, `GPT(Codex) 연결됨`, `인스타 스킬: …`.

## 사용 방법

화면은 왼쪽 **설정**, 가운데 **미리보기·수정**, 오른쪽 **내 영상** 목록으로 나뉜다.

### 1. 영상 만들기
1. **1. 콘텐츠 소스**에 아래 중 하나 이상을 넣는다.
   - 상품 상세페이지 URL (로그인이 필요하거나 수집을 막는 사이트는 안 될 수 있음)
   - 내 자료: 상품명, 특징, 색상, 크기, 원산지 등 텍스트
   - 사진·영상 파일 (여러 개 가능). 이것만 넣어도 AI 가 직접 보고 대본을 쓴다
2. 필요한 설정을 고른다 (모두 기본값으로 두어도 된다).

   | 칸 | 설정 |
   |---|---|
   | 2. 상점 표시 | 상점명(워터마크), 위치 자동/수동, AI 제작 표기 |
   | 3. 템플릿 | 다이내믹 자막형, 콜라주 형태, 검색 시나리오형, 프리미엄 블랙형 |
   | 4. 영상 | 길이 20~60초, 템포, 이미지 움직임, 장면 전환, 글자를 영상 위(고정)/이미지 위(같이 움직임) |
   | 5. 음성·사운드 | AI 음성 6종(▶ 미리듣기), BGM(AI 추천/없음/직접 추가), BGM 볼륨, 효과음, 내레이션 자막 |
   | 6. 텍스트 디자인 | 제목·설명(자막)·브랜드(상점명) 각각 글꼴, 크기, 색, 테두리, 그림자, 배경, 자간, 줄간격, 정렬, 위치 |
   | 7. 출력 | 1080×1920 / 720×1280, 30 / 60fps, MP4 |
   | 8. AI 설정 | 모델(Claude Opus·Sonnet·Haiku / GPT-5.6 Terra·Luna), 추론 수준 |

3. **AI로 영상 만들기**를 누른다. 보통 1~3분 걸리고, 진행 상황이 가운데 로그에 나온다.
4. 끝나면 가운데에서 바로 재생된다. 인스타 스킬이 있으면 **훅 후보 3개**(★ 가 채택된 것)도 함께 보인다.

> AI 를 부를 때마다 고른 쪽(Claude 또는 ChatGPT) 계정 사용량이 차감된다.

### 2. 고치기
수정할 때마다 새 버전(v2, v3 …)이 생기고 이전 버전은 그대로 남는다.

- **말로 수정하기** (AI 사용): 예) `첫 장면 제목을 더 크게, 마지막 장면을 1초 늘려줘, 전체 배경을 밝은 톤으로`.
  지금 보고 있는 버전을 기준으로 고친다.
- **장면 직접 수정** (AI 사용 안 함, 사용량 차감 없음):
  - 장면마다 내레이션, 화면 큰 글씨, 길이, 글씨 크기, 움직임을 고친다
  - 이미지를 누르면 다음 사진·영상으로 바뀐다. 영상 장면은 시작 지점(초)을 정할 수 있다
  - `+ 장면`으로 추가, `✕`로 삭제. 검색어(검색 시나리오형)와 배경 밝기도 여기서 고친다
  - **왼쪽 설정 + 장면 수정으로 다시 만들기**를 누르면 왼쪽 설정(템플릿, 음성, 글꼴 등) 변경도 함께 반영된다
- **버전 기록**: `v1`, `v2` … 를 눌러 비교한다. 예전 버전을 보다가 **이 버전으로 복원**을 누르면 그 버전이 새 버전으로 복사된다.

### 3. 저장과 업로드 준비
- **MP4 저장**: 왼쪽 칸에 적은 폴더(기본: 다운로드)로 영상을 복사한다.
- **썸네일 만들기**: 첫 장면으로 1000×1000 썸네일을 만든다.
- **캡션 만들기** (인스타 스킬 ig-caption, AI 사용): 영상에 맞는 인스타그램 캡션과 해시태그를 쓰고 **복사** 버튼을 준다.
  점검 결과(caption.py)는 영어 기준이라 한글 해시태그 개수·숫자·요청 문구 판정은 참고만 한다.
- 업로드는 자동으로 하지 않는다. 저장한 MP4 와 캡션을 직접 올린다.

### 파일 위치
- 만든 영상: `shorts_out/<날짜_상품명>/<날짜_상품명>_v1.mp4`
- 버전별 대본·설정: `shorts_out/<프로젝트>/v1/plan.json`, `opts.json`
- 캡션: `shorts_out/<프로젝트>/caption_v1.txt`
- BGM 직접 추가: `bgm/` 폴더에 mp3·wav 를 넣어도 된다 (상업적 이용 가능한 음원만)

### 명령어로 쓰기 (선택)
화면 없이 PowerShell 에서도 같은 작업을 할 수 있다. 전체 옵션은 `python shorts.py --help`.
```
python shorts.py new https://상품URL --shop 메이커몰
python shorts.py new --info 상품정보.txt --images 사진폴더 --template collage
python shorts.py edit shorts_out/프로젝트 "첫 장면 제목을 더 크게"
python shorts.py caption shorts_out/프로젝트
python shorts.py restore shorts_out/프로젝트 2
python shorts.py thumb shorts_out/프로젝트
```

### 문제 해결
| 증상 | 해결 |
|---|---|
| `Claude Code 로그인 필요` | PowerShell 에서 `claude` 실행 → `/login` |
| `GPT(Codex) 오류: usage limit` | ChatGPT 계정 한도 초과. 안내된 날짜 이후 다시 하거나 Claude 모델 사용 |
| `포트를 이미 쓰고 있습니다` | 이미 켜 둔 생성기 창을 Ctrl+C 로 끄고 다시 실행 |
| URL 로 만들 때 오류가 나거나 정보가 비어 있음 | 수집을 막는 사이트. 내 자료 칸에 직접 쓰거나 사진을 올린다 |
| 수정했는데 화면이 그대로 | 코드를 바꾼 뒤에는 생성기를 껐다 다시 켠다 |

## 인스타그램 스킬 (선택)
`~/.claude/skills` 에 `ig-reel`, `ig-human`, `ig-caption` 이 있으면 자동으로 쓴다. 없으면 건너뛴다.
- ig-reel: 훅 공식 26개로 훅 후보 3개를 쓰고 가장 좋은 것을 첫 장면에
- ig-human: `humanize.py` 로 대본·캡션의 줄표·숨은 문자 제거
- ig-caption: "캡션 만들기" 버튼, `caption.py` 점검 (영어 기준이라 한글 판정 일부는 참고용)
